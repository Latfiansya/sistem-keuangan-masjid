# Peta desain dan halaman React

Desain resmi berasal dari frame Figma anggota tim. Placeholder saat ini hanya memverifikasi routing dan layout bersama; belum merupakan implementasi desain final.

| Halaman React | Route | URL frame Figma | Status desain | Status implementasi |
| --- | --- | --- | --- | --- |
| Beranda (`HomePage`) | `/` | Belum tersedia | Menunggu frame resmi | Placeholder dan contoh service health |
| Profil Masjid (`ProfilePage`) | `/profil` | Belum tersedia | Menunggu frame resmi | Placeholder |
| Laporan Keuangan (`FinancialReportPage`) | `/laporan-keuangan` | Belum tersedia | Menunggu frame resmi | Placeholder |
| Halaman tidak ditemukan (`NotFoundPage`) | `*` | Belum tersedia | Belum ditentukan | Placeholder fungsional |

`PublicLayout` menampung Navbar, area konten, dan Footer bersama. Desain komponen bersama juga menunggu referensi resmi. Perbarui tabel dengan tautan frame sebenarnya dan status persetujuannya setelah diberikan pengguna; jangan mengarang URL atau menganggap desain telah final.
